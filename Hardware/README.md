# AMV-01 Hardware

This directory contains the mechanical and electronic hardware
development for the Autonomous Mini-Vehicle (AMV-01).

## Current Status

🚧 Hardware architecture and component selection have not yet been finalized.

Hardware will be selected after the system requirements and system
architecture have been defined.

## Planned Areas

### Mechanical
Physical vehicle platform, initially planned around a modular
LEGO/LEGO Technic prototype, with 3D-printed components considered
where required by the mechanical design.

### Electronics
Electronic hardware required for vehicle control, sensing,
communication, actuation, and power management.

This may include development boards, PCB modules, motor drivers,
sensor interfaces, communication interfaces, and potentially a
custom PCB if justified by the final architecture.

### Sensors
Sensors required for perception and vehicle-state measurement.

LiDAR-based environment sensing is currently planned, while the
final sensor set will be derived from the system requirements.

## Engineering Approach

Hardware components will not be selected solely based on availability.

The planned process is:

System Requirements
        ↓
System Architecture
        ↓
Hardware Requirements
        ↓
Interface Requirements
        ↓
Component Evaluation
        ↓
Component Selection
        ↓
Prototype
        ↓
Integration
        ↓
Verification
