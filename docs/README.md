# Engineering Documentation

This directory contains the controlled engineering documents for AMV-01.

The project is intentionally developed from the **system definition and requirements outward**. Hardware and software decisions should be justified by the engineering artifacts created here.

## Document Set

- `01_system_definition/` — problem, mission, stakeholders, boundary, operational context and ConOps
- `02_stakeholder_requirements/` — stakeholder needs and requirements
- `03_system_requirements/` — system-level requirements
- `04_hw_sw_requirements/` — derived hardware and software requirements
- `05_architecture/` — system architecture and allocation
- `06_interfaces/` — interface definitions
- `07_verification_validation/` — verification and validation planning

Documents begin as drafts and are baselined only after review.
